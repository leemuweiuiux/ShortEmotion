跟踪清单

待确认的指数要满足这些条件，才算二波启动：放量至峰值的 60% 以上、当日涨幅 ≥ +2%，且次一交易日量能不回落（近 2 日均量 ≥ 峰值的 55%）。

怎么看
  • 已启动：先缩量，再放量至峰值的 60% 以上、当日涨幅 ≥ +2%，且近 2 日量能确认。
  • 待确认：缩量到位（量能水位 ≤ 0.40 且仍在缩量，或缩量质量 ≥ 65），且抗跌 ≥ -5%，等待放量。
  • 点任一指数可以看近 25 个交易日的成交额与涨跌幅，以及每一项的计算明细。
计算口径
  • 量能：水位 = 近 5 日平均成交额 / 窗口峰值成交额；趋势 = 近 5 日均额 / 前 5 日均额（< 1 表示仍在缩量）；地量 = 近 10 日最低单日成交额 / 峰值。
  • 缩量质量分 = 水位 40% + 趋势 35% + 连续性 25%（连续性 = 地量确认 50% + 连缩天数 50%）。
  • 抗跌度 = (1 + 指数区间涨幅) / (1 + 万得全A 区间涨幅) − 1，区间约 25 个交易日；放量比 = 当日成交额 / 峰值成交额。
  • 总分 = 缩量质量 40% + 抗跌 35% + 启动 25%，各项归一到 0–100；当日涨幅 ≥ 2% 时启动项额外 +10（上限 100）。
  • 分档：已启动（先出现过缩量，放量比 ≥ 0.60、当日涨 ≥ 2%，近 2 日均量 / 峰值 ≥ 0.55 确认）→ 待确认（水位 ≤ 0.40 且趋势 ≤ 0.90，或缩量质量 ≥ 65；抗跌 ≥ -5%；主力净流出时降为观察）→ 观察 → 退潮。历史不足一个多月的指数不计算。
  • 阈值为经验口径，适用于存量博弈市场；指数口径不代表个股；本页为技术形态统计，仅用于研究与情绪观察，不构成投资建议。
